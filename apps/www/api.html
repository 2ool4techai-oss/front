API Reference

Complete reference for all exported functions, types, and classes in the DRISHTI framework.

Signals — @nexoraaidrishti/runtime

function signal<T>(initialValue: T): Signal<T>
Creates a reactive signal. Read with sig(), write with sig.set(value). All computed() and effect() that read this signal re-run when it changes. Writes are synchronous and immediately propagate through the dependency graph.
function computed<T>(fn: () => T): ComputedSignal<T>
Creates a memoized derived signal. The function is called lazily and only re-runs when its signal dependencies change. The returned value is read-only — call it as a function to get the current value. Never throws inside computed; errors propagate to the reading context.
function effect(fn: () => void | (() => void)): () => void
Runs the given function immediately and re-runs it whenever its reactive dependencies change. Optionally returns a cleanup function that runs before the next execution. The return value is a dispose function — call it to permanently stop the effect.
function batch(fn: () => void): void
Groups multiple signal writes into a single atomic flush. All effects and computeds that depend on any of the written signals re-run exactly once after the batch completes. Batches may be nested.
function untrack<T>(fn: () => T): T
Executes the function without tracking any signal reads as dependencies. Use inside effects or computed functions when you need to read a signal without subscribing to its changes.
function createStore<T extends object>(init: T): Store<T>
Creates an object-shaped reactive store with fine-grained per-property tracking. Direct property access and assignment work naturally. Only effects that read a specific property re-run when that property changes.
function label<T>(sig: Signal<T>, name: string): Signal<T>
Attaches a human-readable name to a signal. Named signals appear in _getDevSignals(), audit logs, and OTel traces, making it easy for AI agents and developers to identify specific signals by purpose.

Renderer — @nexoraaidrishti/runtime

function h(tag: string, attrs: Record<string, unknown>, ...children): HTMLElement
Creates a live DOM element. Attribute values and children can be signals, reactive functions, or static values. Reactive values are wired directly — when a dependency changes, only that attribute or child text node is updated in place. No virtual DOM intermediary.
function show(condition: () => boolean, then: () => HTMLElement, else?: () => HTMLElement): Node
Conditionally renders one of two branches. The condition is tracked reactively. When it changes, the old branch is removed from the DOM and the new branch is created and inserted. The else branch is optional — if omitted, a comment node placeholder is used.
function each<T>(list: () => T[], key: (item: T) => string | number, render: (item: T, index: number) => HTMLElement): Node
Keyed list rendering. When the list changes, only the items that were added, removed, or reordered are touched. Items that remain at the same key are not re-created. The key function must return a stable unique identifier per item.
function mount(component: () => HTMLElement, container: HTMLElement): () => void
Mounts a component function into the given container. Returns a dispose function. Unlike mountApp, this does not set up a top-level error boundary and is intended for embedding sub-trees.
function mountApp(component: () => HTMLElement, container: HTMLElement): () => void
Top-level application mount with a global error boundary, devtools integration, and automatic cleanup on dispose. Returns a function that unmounts the app, stops all effects, and removes all DOM nodes created by the app.
function portal(component: () => HTMLElement, target?: HTMLElement): HTMLElement
Renders content into a DOM node outside the component tree. Useful for modals, tooltips, and notification toasts that must escape overflow:hidden or z-index stacking contexts. Defaults to document.body if no target is provided.

State Machines — @nexoraaidrishti/runtime

function createMachine<TState, TEvent>(config: MachineConfig): MachineHandle
Creates an XState-inspired typed state machine. The config defines states and their transitions. Guards block transitions conditionally; entry/exit hooks run as side effects. The returned handle exposes a reactive state() signal and imperative send()/can() methods.
MachineHandle: { state(): TState; send(event: TEvent): void; can(event: TEvent): boolean; history(): entry[]; done(): boolean }
Handle returned by createMachine(). state() is a reactive signal — reading it in effects or computed values creates a dependency. can(event) checks whether the transition is valid from the current state without sending. history() returns all past transitions with timestamps.

Time Travel — @nexoraaidrishti/runtime

function enableTimeTravel(opts?: TimeTravelOptions): TimeTravelHandle
Activates time-travel debugging. All subsequent signal writes are recorded in a ring buffer (default: 500 entries). Must be called before mounting your app. Returns a handle for snapshot, restore, and replay operations.
TimeTravelHandle: { snapshot(): Snapshot; restore(s: Snapshot): void; travel(n: number): void; entries(): Signal<entry[]>; present(): ComputedSignal<number> }
snapshot() captures a full copy of all current signal values. restore(s) resets all signals to a prior snapshot. travel(n) steps forward (positive) or backward (negative) through the write history, applying or reverting each write. present() is the current cursor index as a reactive signal.

Data Fetching — @nexoraaidrishti/runtime

function createResource<T>(fetcher, opts?): Resource<T>
Wraps an async operation in a reactive resource. The fetcher re-runs automatically when any signals it reads change. Returns an object with reactive data(), loading(), error(), and refetch() signals.
function createMutation<T, V>(mutator, opts?): Mutation<T, V>
Creates a mutation handle for write operations with loading, error, and success state. Integrates with createCache for automatic cache invalidation on success. Supports optimistic updates via opts.optimistic.
function createCache<T>(opts): Cache<T>
Creates a reactive key-value cache with TTL, LRU eviction, and manual invalidation. Cache hits prevent redundant network requests. Integrates with createResource and createQuery.
function createQuery<T>(key, fetcher, opts?): QueryResult<T>
React Query-inspired data fetching. Automatically deduplicates concurrent requests with the same key, caches results, and supports stale-while-revalidate. The key is reactive — if it changes, the query re-runs. Supports background refetch, retry, and pagination.
function invalidateQuery(key: string | unknown[]): void
Marks a query as stale and triggers a background refetch for all active query subscribers with a matching key. Partial key matching is supported for cache groups.

Routing — @nexoraaidrishti/runtime

function createRouter(routes: RouteConfig[], opts?): Router
Creates a client-side router from a flat or nested route config. Supports dynamic segments (:id), catch-all routes (*), and route guards. The active route is exposed as a reactive signal on the returned handle.
function useRouter(): Router
Returns the active router instance. Throws if called outside a mounted app tree with no router configured. Use this to access router.location(), router.push(), and router.params() from any component.
Router: { location(): RouteLocation; push(path: string): void; replace(path: string): void; back(): void; forward(): void }
location() is a reactive signal with pathname, params, query, and hash. Reading location() inside an effect or computed re-runs it on navigation. push() adds to the history stack; replace() replaces the current entry.

Forms — @nexoraaidrishti/runtime

function createForm<T>(schema, opts?): Form<T>
Creates a reactive form with schema-driven field-level validation. Each field in the schema defines an initial value, synchronous or async validator, and optional transform. Returns a Form object with per-field state signals and overall validity.
Form<T>: { fields: Record<keyof T, FieldState>; valid(): Signal<boolean>; submit(): void; reset(): void }
Each FieldState has reactive value(), error(), touched(), and dirty() signals. valid() is true when all fields pass validation. submit() touches all fields, validates, and calls opts.onSubmit with typed values if valid. reset() restores all fields to their initial values.

LLM & AI — @nexoraaidrishti/runtime

function createLLMStream(opts: LLMStreamOptions): LLMStreamHandle
Creates a streaming LLM connection. Calls opts.onChunk for each token, opts.onTool for tool calls, and opts.onDone on completion. The handle exposes start(), abort(), and a reactive status() signal ('idle' | 'streaming' | 'done' | 'error').
function createThinkingState(): ThinkingState
Creates a reactive thinking/reasoning state object for UIs that display LLM extended thinking. Exposes thinking() (boolean signal) and thoughts() (accumulated thinking text signal).
function createToolCallState(): ToolCallState
Manages reactive state for in-flight tool calls during LLM streaming. Tracks each tool call's name, arguments, and result status as reactive signals for display in tool-use UIs.
function createIntentEngine(opts): IntentEngine
Creates an intent detection engine that observes signal writes and user interactions to infer what the user is trying to accomplish. Calls opts.onIntent with a structured intent object including action, params, and confidence score. Used by AI agents to proactively suggest next actions.
function _setSignalWriteHook(hook: ((label: string, prev: unknown, next: unknown) => void) | null): void
Registers a global hook that runs synchronously after every signal write. Receives the signal label, previous value, and next value. Pass null to remove the hook. Used by AI agents, OTel tracers, and audit logs to observe all state changes.
function _getDevSignals(): Record<string, Signal<unknown>>
Returns a snapshot of all labeled signals in the current app, keyed by their label strings. AI agents use this to discover the full app state model and gain read/write access to every reactive value without DOM traversal.
function _enableDevMode(): void
Enables development mode, which activates enhanced error messages, signal labeling warnings, effect cycle detection, and the browser devtools panel. Should not be called in production builds.

Collaboration — @nexoraaidrishti/runtime

function createCollabSession(opts: CollabOptions): CollabHandle
Creates a CRDT-backed collaborative session using vector clocks for conflict-free concurrent edits. Connects over WebSocket and supports automatic reconnection and offline queuing. Returns a handle for syncing signals and observing peer presence.
CollabHandle: { sync(key: string, sig: Signal): void; peers(): Signal<Peer[]>; send(op): void; disconnect(): void }
sync(key, signal) binds a local signal to a shared CRDT document field — writes propagate to all peers, and incoming ops are merged conflict-free. peers() is a reactive signal listing all connected peers with their presence data. disconnect() cleanly closes the session.

Production — @nexoraaidrishti/runtime

function createAuditLog(opts?): AuditHandle
Creates a ring buffer that records every signal write for compliance and debugging. The buffer size is configurable. When full, oldest entries are evicted. Exposes a reactive entries() signal and an onFlush callback for batching writes to a backend.
function enableHIPAA(opts?): HIPAAHandle
Activates automatic PII scrubbing for SSN, email, phone numbers, and credit card data in all audit logs and error reports. Regex-based scrubbing runs in the signal write hook pipeline. Fields matching configured patterns are replaced before being recorded.
function createConsentManager(opts): ConsentHandle
GDPR-compliant consent management. Exposes per-category granted(category) reactive signals. Signals that depend on consent automatically pause when consent is revoked and resume when it's granted. Persists choices to localStorage by default.
function createCSP(opts?): CSPHandle
Generates Content-Security-Policy headers and per-request nonces for inline scripts and styles. In SSR mode, a new nonce is generated for each request. csp.nonce() returns the current nonce as a string; csp.header() returns the full CSP header value.
function createRUM(opts?): RUMHandle
Real User Monitoring via the PerformanceObserver API. Collects Largest Contentful Paint, First Contentful Paint, Cumulative Layout Shift, First Input Delay, and Time to First Byte. All vitals are exposed as reactive signals and reported via opts.onVital.
function createOtelTracer(opts): OtelHandle
Emits OpenTelemetry spans for signal writes, effect runs, and component renders. Compatible with any OTLP-capable backend (Jaeger, Zipkin, Grafana Tempo, Honeycomb). Configurable sampling rate and attribute filtering.
function createErrorTracker(opts): ErrorTrackingHandle
Captures uncaught errors and unhandled promise rejections with signal state snapshots attached. Sends structured error reports to a configurable endpoint. Integrates with createAuditLog to include the last N signal writes as breadcrumbs.

Persistence — @nexoraaidrishti/runtime

function persistSignal<T>(key: string, signal: Signal<T>, opts?): () => void
Syncs a signal to a storage backend. On startup, the signal is initialized from the stored value if present. On every write, the new value is serialized and saved. Supports localStorage, sessionStorage, IndexedDB, and custom adapters via opts.storage. Returns an unsubscribe function.
function createPersistedStore<T>(key: string, init: T, opts?): Store<T>
Creates a store where the entire object is persisted to storage and restored on startup. Individual property changes are debounced before writing to avoid excessive I/O. Useful for user preferences and session state that spans page reloads.

Feature Flags — @nexoraaidrishti/runtime

function createFlag(key: string, config: FlagConfig): FlagHandle
Creates a reactive feature flag. Supports boolean flags, multi-variant flags, and user-targeting rules. The flag value is a reactive signal — changing the flag configuration updates all dependent UI instantly without a page reload.
function createBandit(opts): BanditHandle
Multi-armed bandit for A/B testing with automatic traffic allocation. Supports epsilon-greedy, UCB1, and Thompson sampling algorithms. Tracks conversion events per arm and adjusts allocation toward the winning variant over time.
function createAutoRollout(opts): AutoRolloutHandle
Gradually rolls out a feature flag from 0% to 100% based on configurable success metrics. Monitors error rates, conversion events, and custom signals. Automatically pauses or rolls back if metrics degrade beyond configured thresholds.

Dev Tools — @nexoraaidrishti/runtime

function _enableDevMode(): void
Enables all development-time checks: enhanced error messages with signal stack traces, cycle detection in effect graphs, label collision warnings, and the browser devtools panel integration.
function _getDevSignals(): Record<string, Signal<unknown>>
Returns all signals that have been labeled via label(), keyed by their label strings. Use this in devtools, AI agents, or testing utilities to inspect and mutate the full application state map.
function _setSignalWriteHook(hook): void
Sets a global write interceptor called synchronously on every signal write. The hook receives (label: string, prev: unknown, next: unknown). Only one hook can be active at a time. Pass null to remove. Used internally by createAuditLog and createOtelTracer.
function _totalEffectRuns(): number
Returns the total count of effect executions since the page loaded. Useful for profiling and verifying that batching strategies are working correctly. Only meaningful in development builds.

SSR — @nexoraaidrishti/ssr

function renderToString(component, context?): Promise<string>
Renders a DRISHTI component to an HTML string on the server. Executes all synchronous signal reads, resolves all resources without suspending, and serializes the resulting DOM tree. The client automatically hydrates from the serialized signal state embedded in the HTML.
function renderToStream(component, context?): ReadableStream
Streaming SSR — flushes the shell HTML immediately and streams suspended content as it resolves. Works on any runtime that supports the Web Streams API, including Node.js 18+, Deno, Cloudflare Workers, and Vercel Edge Runtime.
function createSuspense(fallback, contentFn): SuspenseBoundary
Creates a suspense boundary for async data in SSR mode. During server rendering, shows the fallback until all async resources inside resolve. In streaming mode, the fallback is flushed immediately and the resolved content is streamed when ready.

Testing — @nexoraaidrishti/testing

function render(component, opts?): RenderResult
Renders a component into a detached DOM node for testing. Returns { el, cleanup, getBy*, queryBy*, findBy* }. Effects run synchronously in the test environment. Call cleanup() to dispose the component and remove the DOM.
fireEvent: { click, input, keydown, keyup, submit, change, focus, blur, ... }
Dispatches DOM events and flushes all reactive effects synchronously. Each method accepts an element and an optional event init object. Effects triggered by the event are guaranteed to complete before the function returns.
function waitFor(condition, opts?): Promise<void>
Polls the condition function until it passes without throwing, or until the timeout is reached. Use for async operations where effects don't fire synchronously (e.g. after a fetch resolves). Default timeout is 1000ms with 50ms polling interval.
function auditA11y(element, opts?): Promise<A11yReport>
Runs WCAG 2.2 accessibility checks against the given element using axe-core under the hood. Returns a report with violations, passes, and incomplete arrays. Each violation includes the WCAG criterion, affected nodes, and suggested fixes.
function assertA11y(element, opts?): Promise<void>
Runs the same WCAG 2.2 audit as auditA11y() but throws a descriptive error if any violations are found. Use in test assertions to enforce accessibility standards automatically on every component test.
function takeSnapshot(el: HTMLElement, name: string): VisualSnapshot
Captures a pixel snapshot of the element for visual regression testing. On the first run, the snapshot is saved as the baseline. On subsequent runs, the current render is compared against the baseline.
function diffVisualSnapshots(before, after, opts?): VisualDiff
Computes a pixel-level diff between two snapshots. Returns a VisualDiff with the diff percentage, a diff image, and the coordinates of changed regions. Useful for debugging visual regression failures.
function assertVisualMatch(el: HTMLElement, baseline: string, opts?): void
Captures a snapshot and asserts it matches the named baseline within a configurable pixel diff threshold (default: 0.1%). Throws a descriptive error on failure with the diff image path and changed pixel count.
function expectSignal(sig: Signal<unknown>): SignalAssertion
Returns a chainable assertion object for a signal. Supports .toBe(value), .toEqual(value), .toHaveBeenCalledWith(...values), and .toHaveLength(n). The assertion reads the signal value at call time without creating a reactive dependency.

AI Generate — @nexoraaidrishti/runtime

function generate(opts: GenerateOptions): Promise<GenerateResult>
Generates a UI component from a natural-language prompt using an LLM backend. Returns structured HTML and signal bindings. opts.prompt describes the component; opts.signals maps existing signals to inject into the generated component.
function generateSync(opts: GenerateOptions): GenerateResult
Synchronous variant of generate() for use in contexts where async is not available. Uses a cached LLM response or a local template fallback. Throws if no matching template is found and no cache entry exists.

Voice Signals — @nexoraaidrishti/runtime

function createVoiceSignal<T>(initial: T, opts?): VoiceSignal<T>
Creates a signal that can be controlled by voice commands via the Web Speech API. opts.commands maps spoken phrases to signal values. Returns a standard signal augmented with .start(), .stop(), and .supported.
function voiceControl(target: Signal<string>, opts?): VoiceHandle
Attaches voice transcription to an existing string signal. Continuously writes recognized speech into the signal. opts.lang sets the BCP 47 language tag. Returns a handle with start(), stop(), and reactive listening() signal.

Signal Permissions — @nexoraaidrishti/runtime

function withPermissions<T>(sig: Signal<T>, policy: PermissionPolicy): Signal<T>
Wraps a signal with role-based access control. policy.read and policy.write accept arrays of role strings. Unauthorized reads return undefined; unauthorized writes throw PermissionError. All access attempts are recorded in the audit log.
function getAuditLog(): AuditEntry[]
Returns all recorded permission audit events. Each entry includes timestamp, label, action ('read' | 'write'), role, and allowed boolean.
class PermissionError extends Error
Thrown when a write is attempted on a permission-guarded signal by an unauthorized role. Contains signal, role, and action properties for structured error handling.

NL Queries — @nexoraaidrishti/runtime

function drQuery(query: string): unknown
Executes a natural-language query against all registered queryable signals. Returns the first matching result. Queries support patterns like "named Alice", "count greater than 5", and "status is active".
function registerQueryable(label: string, sig: Signal<unknown>): void
Registers a signal with the NL query registry under a human-readable label. Registered signals can be queried via drQuery() and queryLocally().
function queryLocally(data: unknown[], query: string): unknown[]
Runs a natural-language filter against an in-memory array. Supports name matching ("named X"), numeric comparisons, and status filters without an external LLM call.

Semantic Signals — @nexoraaidrishti/runtime

function semanticSignal<T>(initial: T, description: string): Signal<T>
Creates a signal with a semantic description for AI agents. The description is stored in the semantic registry and returned by describeAppState() for LLM consumption. Semantically described signals help AI agents understand intent without reading source code.
function describeAppState(): string
Returns a human-readable summary of all semantically registered signals and their current values, formatted as a prose description suitable for inclusion in an LLM system prompt.

AI Trace — @nexoraaidrishti/runtime

function createAITrace(opts?): AITrace
Creates a structured audit trail for AI agent actions. Records every agent decision, signal write, and tool call with timestamps, agent ID, confidence scores, and reasoning. Exports to JSON or OpenTelemetry spans.
globalTrace: AITrace
A pre-created global AITrace instance that is active as soon as the runtime loads. Any AI agent can log to it without creating their own trace instance.

Screen Schema — @nexoraaidrishti/runtime

function captureScreenSchema(): ScreenSchema
Captures a structural schema of the current rendered UI — all interactive elements, their roles, labels, and bound signal values — without capturing pixel data. The schema is safe to send to an LLM.
function schemaToPrompt(schema: ScreenSchema): string
Converts a ScreenSchema into a compact, structured text description suitable for inclusion in an LLM prompt. Describes all interactive elements and their current state.

Predictive Routing — @nexoraaidrishti/runtime

function createPredictiveRouter(routes: RouteConfig[], opts?): PredictiveRouter
Extends the standard router with ML-based route prefetching. Tracks navigation patterns and prefetches the most likely next routes. opts.prefetchThreshold controls the minimum confidence (0–1) before prefetching. Prefetched routes load instantly.

Offline Signals — @nexoraaidrishti/runtime

function offlineSignal<T>(key: string, initial: T): OfflineSignal<T>
Creates a signal that persists offline writes to IndexedDB and replays them when the connection is restored. Writes made while offline are queued and applied in order on reconnection. Exposes a .pending() reactive signal with the count of queued writes.
function isOnline(): Signal<boolean>
Returns a reactive signal that tracks navigator.onLine. Updates automatically when the browser goes online or offline.
function onceOnline(fn: () => void): void
Calls fn immediately if online, or defers it until the next time the browser comes online. The callback fires at most once.

Cross-Session Adaptive — @nexoraaidrishti/runtime

function adaptiveSignal<T>(key: string, initial: T): Signal<T>
Creates a signal whose value is persisted across browser sessions and updated by ML-based personalization. Each time the user interacts, the stored preference is updated. On the next session, the signal initializes to the learned preference.
function createLearningProfile(opts?): LearningProfile
Creates a user learning profile that tracks interaction patterns across signals. Exposes recommend(key) which returns the most likely preferred value for a signal based on history.

Decay Signals — @nexoraaidrishti/runtime

function createDecaySignal<T>(initial: T, opts: DecayOptions): DecaySignal<T>
Creates a signal that automatically resets to a default value after a configurable idle period. opts.resetTo is the value to decay back to. opts.afterMs is the idle timeout. opts.onDecay is an optional callback. Useful for ephemeral UI state like notifications or hover highlights.

Context Profiles — @nexoraaidrishti/runtime

function createContextProfile(name: string, conditions: ContextConditions): ContextProfile
Defines a named context (e.g., 'mobile', 'night', 'slow-connection') with detection conditions. When the conditions are met, the profile activates and all signals bound to it via useContextAdaptiveSignal() switch to their profile-specific values.
function useContextAdaptiveSignal<T>(defaults: Record<string, T>): Signal<T>
Creates a signal that automatically returns a different value based on the active context profile. defaults maps profile names to values. The 'default' key is used when no profile matches.

Attention Tracking — @nexoraaidrishti/runtime

function createAttentionTracker(opts?): AttentionTracker
Tracks user attention using the Page Visibility API and IntersectionObserver. Exposes reactive focusedMs(), blurredMs(), isVisible(), and attentionScore() signals. Useful for analytics, adaptive content loading, and pausing animations when the tab is not visible.

Preference Merge — @nexoraaidrishti/runtime

function preferenceSignal<T>(key: string, defaults: T, sources: PreferenceSource[]): Signal<T>
Merges preferences from multiple sources (URL params, localStorage, user profile API, system defaults) with configurable priority ordering. The merged value is reactive — when any source updates, the signal recomputes the merged preference.

Multi-Modal Input — @nexoraaidrishti/runtime

function createMultiModalInput(opts?): MultiModalHandle
Creates an input handler that normalizes keyboard, touch, pointer, and gamepad events into a unified reactive stream. Exposes signals for activeModality(), lastInput(), and per-modality event streams.
function adaptToModality<T>(values: ModalityMap<T>): Signal<T>
Returns a signal whose value adapts to the current input modality. values.keyboard, values.touch, and values.pointer define the value for each modality. The signal switches automatically as the user changes input method.

Lazy Signal Split — @nexoraaidrishti/runtime

function lazySignal<T>(loader: () => Promise<T>): Signal<T | undefined>
Creates a signal whose initial value is loaded asynchronously. The signal is undefined until the loader resolves. Useful for code-split signal modules that are expensive to initialize.
function prefetchWhen(condition: () => boolean, loader): void
Triggers prefetching of a lazy signal module when a condition becomes true. Use with hover or proximity signals to preload heavy modules before the user navigates to them.

Signal Integrity — @nexoraaidrishti/runtime

function createIntegritySignal<T>(initial: T, opts: IntegrityOptions<T>): Signal<T>
Creates a signal that verifies data integrity on every write using a hash or custom verifier. opts.hash computes a hash of the value; opts.verify checks the hash against the value. Throws IntegrityError if verification fails.
class IntegrityError extends Error
Thrown by createIntegritySignal when a write fails integrity verification. Contains expected and actual hash properties.

Private Signals — @nexoraaidrishti/runtime

function privateSignal<T>(initial: T, opts?): Signal<T>
Creates a signal marked as private. Private signals are excluded from _getDevSignals() output, AI agent discovery, audit logs, and OTel traces. Use for passwords, tokens, and other sensitive ephemeral values.
function isPrivateSignal(sig: Signal<unknown>): boolean
Returns true if the given signal was created with privateSignal() or marked with markAsPrivate(). Use in dev tools and audit systems to gate logging.

Rate-Limited Signals — @nexoraaidrishti/runtime

function rateLimitSignal<T>(initial: T, opts: RateLimitOptions): Signal<T>
Creates a signal that enforces a maximum write frequency. opts.maxWrites and opts.windowMs define the rate limit (e.g. 10 writes per second). Exceeding the limit throws RateLimitError. Useful for protecting AI inference signals from excessive polling.
class RateLimitError extends Error
Thrown when a rate-limited signal receives more writes than its configured rate allows within the window. Contains limit, windowMs, and retryAfterMs properties.

XSS Guard — @nexoraaidrishti/runtime

function xssGuardSignal(initial: string, opts?): Signal<string>
Creates a string signal that automatically sanitizes all written values. HTML tags, script injections, and dangerous attributes are stripped or escaped on every write. opts.mode controls the sanitization level: 'strip' (default) removes all tags; 'escape' HTML-encodes them.

Anomaly Detection — @nexoraaidrishti/runtime

function anomalySignal<T>(initial: T, opts: AnomalyOptions<T>): AnomalySignal<T>
Creates a signal that detects anomalous values using configurable detection strategies (z-score, IQR, threshold, or custom). Exposes .anomalies() as a reactive array of flagged writes. opts.onAnomaly is called with the value and detection metadata for alerting.

Type Coercion — @nexoraaidrishti/runtime

function coercedSignal<T>(initial: T, coerce: (v: unknown) => T): Signal<T>
Creates a signal that runs a coercion function on every write. The coercion function receives the raw written value and must return a value of type T. Useful for signals that receive data from external sources (forms, URLs, APIs) that may not be correctly typed.

Dead Signal Detector — @nexoraaidrishti/runtime

function createDeadSignalDetector(opts?): DeadSignalDetector
Creates a detector that monitors registered signals for zero reads and zero writes after a grace period. Calls opts.onDead(label, ageMs) for each stale signal on a configurable interval. No-ops in production when opts.devOnly is true (default).
function watchedSignal<T>(initial: T, label: string, detector: DeadSignalDetector): Signal<T>
Creates a standard signal that is automatically registered with a DeadSignalDetector. All reads and writes are tracked without requiring manual hook wiring.

Circular Dependency Guard — @nexoraaidrishti/runtime

function guardedComputed<T>(fn: () => T, label?: string): ComputedSignal<T>
A drop-in replacement for computed() that detects circular dependencies at runtime and throws CircularDependencyError with a full dependency chain trace instead of hanging or stack-overflowing.
function detectCycles(signals: Signal[]): string[][]
Statically analyses a set of signals and computeds for circular dependencies without executing them. Returns an array of cycle paths (each path is an array of signal labels). Empty array means no cycles detected.
class CircularDependencyError extends Error
Thrown by guardedComputed() when a circular dependency is detected. The cycle property contains the ordered array of signal labels forming the circular chain.

Bounded Array Signals — @nexoraaidrishti/runtime

function boundedSignal<T>(initial: T[], opts: BoundedOptions): BoundedSignal<T>
Creates an array signal with a maximum capacity. When the array exceeds opts.maxLength, the oldest items are evicted. opts.onEvict is called with evicted items for logging or archival. Exposes .push(), .pop(), and .clear() helper methods alongside the standard signal interface.
